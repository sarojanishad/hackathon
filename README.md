# 🛍️ E-Commerce Clothing Website

This is a simple **E-commerce Clothing Website** built using **HTML, CSS, and JavaScript**.  
It showcases a modern clothing store design where users can browse products, read reviews, and contact the store easily.

---

## 🌟 Features

- 🏠 **Home Page** – Displays featured clothing items and store highlights  
- 👗 **Product Section** – Showcases different clothing categories  
- 💬 **Review Section** – Customers can view and read product reviews  
- 📞 **Contact Us Page** – Lets users get in touch with the store  
- 🎨 **Responsive Design** – Works well on both desktop and mobile screens  

---

## 🧰 Technologies Used

- **HTML** – Structure of the website  
- **CSS** – Styling and layout  
- **JavaScript** – Interactivity and dynamic elements
